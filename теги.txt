- <b>: bold (жирный текст)
- <br>: break (разрыв строки)
- <a>: anchor (якорь)
- <p>: paragraph (абзац)
- <img>: image (изображение)
- <ul>: unordered list (маркированный список)
- <ol>: ordered list (нумерованный список)
- <li>: list item (элемент списка)
- <table>: таблица (table)
- <tr>: table row (строка таблицы)
- <td>: table data (ячейка таблицы)
- <h1>-<h6>: heading 1-6 (заголовок 1-6)
- <div>: division (раздел)
- <span>: span (распространение)
- <form>: form (форма)
- <input>: input (ввод)
- <button>: button (кнопка)
- <select>: select (выбор)
- <textarea>: text area (область текста)
- <header>: header (заголовок)
- <footer>: footer (подвал)
- <nav>: navigation (навигация)
- <article>: article (статья)
- <aside>: aside (по сторонам)
- <section>: section (раздел)
